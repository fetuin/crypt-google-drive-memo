KAGIMEMO

鍵メモ セットアップガイド

Googleドライブに置いたメモ・写真・動画・任意のファイルを、スマホからパスワード付きで暗号化して保存・閲覧するための小さなウェブアプリです。Google Apps Scriptで動くので、自分のサーバーやGoogle Cloudの設定は要りません。下のコード2つをコピーして貼り付ければ、10分ほどで使えるようになります。

開発元：usePocket（usepocket.com）

仕組み セットアップ コード 使い方 ファイルサイズ 注意点 ファイル形式

仕組み

スマホのブラウザ パスワードから鍵を作り、ここで暗号化と復号を行う
暗号文だけ
Apps Script 自分のアカウントで動く中継役。一覧・メモの読み書きと、写真・動画用のアクセス許可を担当
読み書き
Googleドライブ マイドライブの「鍵メモ」フォルダに、メモは .txt、写真・動画などは .kgm で保存
  • 暗号方式は AES-256-GCM、パスワードから鍵を作る処理は PBKDF2-SHA256 を60万回。どちらもブラウザ標準の Web Crypto API を使っています。
  • パスワードと平文はブラウザの外に出ません。Apps Script とドライブに届くのは暗号化された文字列だけです。
  • パスワードが違うときや、ファイルが書き換えられているときは開けません（改ざん検出つき）。
  • 写真・動画などは、Apps Script の容量制限を避けるため、ブラウザから Google ドライブへ直接送受信します。4MBずつ暗号化しながら送るので、大きなファイルでも端末のメモリをほとんど使いません。

セットアップ

貼り付け作業があるので、PCで行うのがおすすめです。

  1. Apps Script のプロジェクトを作る

    script.google.com を開き、「新しいプロジェクト」を作ります。左上の「無題のプロジェクト」をクリックして「鍵メモ」などの名前にしておくと、あとで見つけやすくなります。

  2. Code.gs を貼り付ける

    最初からある「コード.gs」の中身をすべて消して、下の Code.gs を貼り付けます。

  3. index.html を追加して貼り付ける

    ファイル一覧の「＋」→「HTML」を選び、名前を index にします（.html は自動で付きます）。中身をすべて消して、下の index.html を貼り付けます。最後に保存（Ctrl+S）します。

  4. ウェブアプリとしてデプロイする

    右上の「デプロイ」→「新しいデプロイ」を開き、歯車アイコンから種類「ウェブアプリ」を選んで、次のように設定します。

    次のユーザーとして実行
    自分
    アクセスできるユーザー
    自分のみ

  5. アクセスを承認する

    「アクセスを承認」を押してアカウントを選びます。「このアプリは Google で確認されていません」と出たら、「詳細」→「鍵メモ（安全ではないページ）に移動」→「許可」と進みます。自分で作ったスクリプトなので問題ありません。

  6. スマホで開いてホーム画面に追加する

    デプロイ完了画面に出る「ウェブアプリ」のURL（https://script.google.com/macros/s/…/exec）をスマホで開きます。ブラウザのメニューから「ホーム画面に追加」しておくと、アプリのように起動できます。

/**
 * 鍵メモ（Google Apps Script版）サーバー側  v2
 *
 * - マイドライブの「鍵メモ」フォルダ内のファイルを一覧・読み書きします。
 * - 暗号化と復号はすべてブラウザ側で行い、ここには暗号文しか届きません。
 * - 画像・動画などのファイルは、ブラウザからDrive APIへ直接アップロード／ダウンロードします
 *   （Apps Scriptの容量制限を受けないようにするため）。そのためのアクセストークンを渡します。
 * - URL末尾に ?id=<ファイルID> を付けると、そのファイルを直接開きます。
 * - デプロイ設定: 種類「ウェブアプリ」/ 実行ユーザー「自分」/ アクセス「自分のみ」
 */

const FOLDER_NAME = '鍵メモ';
const MAGIC = '#kagimemo v1 ';

function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('鍵メモ')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1, viewport-fit=cover');
}

function getFolder_() {
  const it = DriveApp.getFoldersByName(FOLDER_NAME);
  return it.hasNext() ? it.next() : DriveApp.createFolder(FOLDER_NAME);
}

// ファイル内容のハッシュ。ほかの端末での更新（競合）検出に使う
function rev_(s) {
  return Utilities.base64Encode(
    Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, s, Utilities.Charset.UTF_8));
}

function listFiles() {
  const files = getFolder_().getFiles();
  const out = [];
  while (files.hasNext()) {
    const f = files.next();
    if (f.isTrashed()) continue;
    out.push({ id: f.getId(), name: f.getName(), updated: f.getLastUpdated().getTime(), size: f.getSize() });
  }
  out.sort((a, b) => b.updated - a.updated);
  return out;
}

/**
 * ブラウザからDrive APIを直接呼ぶための情報。
 * トークンは約1時間有効で、このウェブアプリを開いた本人の権限でのみ発行されます。
 */
function getDriveAccess() {
  return { token: ScriptApp.getOAuthToken(), folderId: getFolder_().getId() };
}

// ---------- テキストメモ（v1形式） ----------

function readFile(id) {
  const f = getOwnFile_(id);
  const content = f.getBlob().getDataAsString('UTF-8');
  return { id: f.getId(), name: f.getName(), content: content, rev: rev_(content) };
}

/**
 * req = { id?, name?, content, rev?, force? }
 *  id あり: 上書き保存（rev が現在の内容と違えば CONFLICT。force で強制上書き）
 *  id なし: 「鍵メモ」フォルダに新規作成
 */
function saveFile(req) {
  const content = String(req.content || '');
  if (content.indexOf(MAGIC) !== 0) throw new Error('暗号化されていないデータは保存できません。');

  if (req.id) {
    const f = getOwnFile_(req.id);
    if (!req.force && req.rev && rev_(f.getBlob().getDataAsString('UTF-8')) !== req.rev) {
      throw new Error('CONFLICT');
    }
    f.setContent(content);
    return { id: f.getId(), name: f.getName(), rev: rev_(content) };
  }

  let name = String(req.name || '').trim();
  if (!name) throw new Error('ファイル名を入力してください。');
  if (name.length > 100) throw new Error('ファイル名が長すぎます。');
  if (!/\.txt$/i.test(name)) name += '.txt';
  const folder = getFolder_();
  if (folder.getFilesByName(name).hasNext()) throw new Error('「' + name + '」はすでにあります。別の名前にしてください。');
  const f = folder.createFile(name, content, MimeType.PLAIN_TEXT);
  return { id: f.getId(), name: f.getName(), rev: rev_(content) };
}

// ---------- 共通 ----------

// 「鍵メモ」フォルダ内のファイルだけを扱う
function getOwnFile_(id) {
  let f;
  try { f = DriveApp.getFileById(String(id || '')); } catch (e) { throw new Error('ファイルが見つかりません。'); }
  const parents = f.getParents();
  const folderId = getFolder_().getId();
  while (parents.hasNext()) if (parents.next().getId() === folderId) return f;
  throw new Error('「鍵メモ」フォルダのファイルではありません。');
}

// URL（?id=…）で直接開くときのファイル情報
function getFileInfo(id) {
  const f = getOwnFile_(id);
  if (f.isTrashed()) throw new Error('このファイルはゴミ箱に移動されています。');
  return { id: f.getId(), name: f.getName(), updated: f.getLastUpdated().getTime(), size: f.getSize() };
}

// このウェブアプリのURL（ファイルごとのリンク作成用）
function getAppUrl() {
  return ScriptApp.getService().getUrl();
}

// ゴミ箱へ移動（ドライブのゴミ箱から30日以内なら元に戻せます）
function trashFile(id) {
  getOwnFile_(id).setTrashed(true);
  return true;
}

    IV   : nonce(8) || u32(チャンク番号)   メタは u32 = 0xFFFFFFFF
    AAD  : 先頭からヘッダJSONまでのバイト列 || u32(チャンク番号) || 最終チャンクなら1、それ以外0

<script>
const KM = (() => {
  const MAGIC = '#kagimemo v1';
  const DEFAULT_ITER = 600000;
  const te = new TextEncoder(), td = new TextDecoder();

  function b64enc(u8) {
    let s = '';
    for (let i = 0; i < u8.length; i += 0x8000) s += String.fromCharCode.apply(null, u8.subarray(i, i + 0x8000));
    return btoa(s);
  }
  function b64dec(str) {
    const s = atob(str), u = new Uint8Array(s.length);
    for (let i = 0; i < s.length; i++) u[i] = s.charCodeAt(i);
    return u;
  }
  function header(iter) { return `${MAGIC} pbkdf2-sha256 ${iter} aes-256-gcm`; }

  async function deriveKey(pw, salt, iter) {
    const base = await crypto.subtle.importKey('raw', te.encode(pw), 'PBKDF2', false, ['deriveKey']);
    return crypto.subtle.deriveKey(
      { name: 'PBKDF2', salt, iterations: iter, hash: 'SHA-256' },
      base, { name: 'AES-GCM', length: 256 }, false, ['encrypt', 'decrypt']);
  }

  async function encrypt(text, key, salt, iter) {
    const head = header(iter);
    const iv = crypto.getRandomValues(new Uint8Array(12));
    const ct = new Uint8Array(await crypto.subtle.encrypt(
      { name: 'AES-GCM', iv, additionalData: te.encode(head) }, key, te.encode(text)));
    const all = new Uint8Array(28 + ct.length);
    all.set(salt, 0); all.set(iv, 16); all.set(ct, 28);
    return head + '\n' + b64enc(all).replace(/.{1,76}/g, '$&\n');
  }

  function parse(txt) {
    txt = txt.replace(/^﻿/, '');
    const nl = txt.indexOf('\n');
    const head = (nl < 0 ? txt : txt.slice(0, nl)).trim();
    const p = head.split(/\s+/);
    if (p[0] + ' ' + p[1] !== MAGIC || p[2] !== 'pbkdf2-sha256' || p[4] !== 'aes-256-gcm') throw new Error('format');
    const iter = parseInt(p[3], 10);
    if (!(iter >= 1000)) throw new Error('format');
    let data;
    try { data = b64dec(txt.slice(nl + 1).replace(/\s+/g, '')); } catch (e) { throw new Error('format'); }
    if (data.length < 28 + 16) throw new Error('format');
    return { head, iter, salt: data.slice(0, 16), iv: data.slice(16, 28), ct: data.slice(28) };
  }

  async function decrypt(parsed, key) {
    const pt = await crypto.subtle.decrypt(
      { name: 'AES-GCM', iv: parsed.iv, additionalData: te.encode(parsed.head) }, key, parsed.ct);
    return td.decode(pt);
  }

  function newSalt() { return crypto.getRandomValues(new Uint8Array(16)); }

  return { DEFAULT_ITER, deriveKey, encrypt, parse, decrypt, newSalt, b64enc, b64dec };
})();
</script>

<!-- ファイルの暗号処理（.kgm・分割暗号化・DOM非依存） -->
<script>
const KB = (() => {
  const MAGIC = [0x4B, 0x47, 0x4D, 0x42]; // "KGMB"
  const VERSION = 1;
  const CHUNK = 4 * 1024 * 1024;
  const TAG = 16;
  const META_INDEX = 0xFFFFFFFF;
  const te = new TextEncoder(), td = new TextDecoder();

  function u32(n) { const b = new Uint8Array(4); new DataView(b.buffer).setUint32(0, n >>> 0, false); return b; }
  function readU32(u8, off) { return new DataView(u8.buffer, u8.byteOffset, u8.byteLength).getUint32(off, false); }
  function cat(...arrs) {
    let n = 0; for (const a of arrs) n += a.length;
    const out = new Uint8Array(n); let o = 0;
    for (const a of arrs) { out.set(a, o); o += a.length; }
    return out;
  }
  function iv(nonce, i) { return cat(nonce, u32(i)); }
  function aad(prefix, i, final) { return cat(prefix, u32(i), new Uint8Array([final ? 1 : 0])); }
  function chunkCount(size, chunk) { return Math.max(1, Math.ceil(size / chunk)); }
  function ptLen(ctx, i) { return i < ctx.n - 1 ? ctx.chunk : ctx.size - (ctx.n - 1) * ctx.chunk; }

  function makePrefix(h) {
    const json = te.encode(JSON.stringify(h));
    return cat(new Uint8Array(MAGIC), new Uint8Array([VERSION]), u32(json.length), json);
  }

  // 先頭バイト列からヘッダを読む。足りなければ 'short'、形式違いは 'format'
  function parsePrefix(u8) {
    if (u8.length < 9) throw new Error('short');
    for (let k = 0; k < 4; k++) if (u8[k] !== MAGIC[k]) throw new Error('format');
    if (u8[4] !== VERSION) throw new Error('format');
    const hl = readU32(u8, 5);
    if (hl > 4096) throw new Error('format');
    if (u8.length < 9 + hl + 4) throw new Error('short');
    let h;
    try { h = JSON.parse(td.decode(u8.subarray(9, 9 + hl))); } catch (e) { throw new Error('format'); }
    const salt = KM.b64dec(h.salt || ''), nonce = KM.b64dec(h.nonce || '');
    if (h.kdf !== 'pbkdf2-sha256' || h.cipher !== 'aes-256-gcm' || salt.length !== 16 || nonce.length !== 8 ||
        !(h.iter >= 1000 && h.iter <= 1e7) || !(h.chunk >= 65536 && h.chunk <= 64 * 1024 * 1024)) throw new Error('format');
    const prefix = u8.slice(0, 9 + hl);
    const metaLen = readU32(u8, 9 + hl);
    if (metaLen > 60000) throw new Error('format');
    const metaStart = 9 + hl + 4;
    if (u8.length < metaStart + metaLen) throw new Error('short');
    return { h, salt, nonce, prefix, metaCt: u8.slice(metaStart, metaStart + metaLen), dataOffset: metaStart + metaLen };
  }

  // 暗号化の準備。total はアップロードするバイト数（先に分かるのでレジューム可能アップロードに使える）
  async function prepare(file, pw) {
    const salt = KM.newSalt(), nonce = crypto.getRandomValues(new Uint8Array(8));
    const iter = KM.DEFAULT_ITER, chunk = CHUNK;
    const key = await KM.deriveKey(pw, salt, iter);
    const prefix = makePrefix({ kdf: 'pbkdf2-sha256', iter, salt: KM.b64enc(salt), cipher: 'aes-256-gcm', chunk, nonce: KM.b64enc(nonce) });
    const meta = { name: String(file.name || 'file').slice(0, 200), type: file.type || '', size: file.size, mtime: file.lastModified || Date.now() };
    const metaCt = new Uint8Array(await crypto.subtle.encrypt(
      { name: 'AES-GCM', iv: iv(nonce, META_INDEX), additionalData: cat(prefix, te.encode('meta')) }, key, te.encode(JSON.stringify(meta))));
    const head = cat(prefix, u32(metaCt.length), metaCt);
    const n = chunkCount(file.size, chunk);
    return { key, nonce, prefix, chunk, size: file.size, n, head, total: head.length + file.size + n * TAG, file };
  }

  async function encryptChunk(ctx, i) {
    const start = i * ctx.chunk;
    const pt = new Uint8Array(await ctx.file.slice(start, start + ptLen(ctx, i)).arrayBuffer());
    return new Uint8Array(await crypto.subtle.encrypt(
      { name: 'AES-GCM', iv: iv(ctx.nonce, i), additionalData: aad(ctx.prefix, i, i === ctx.n - 1) }, ctx.key, pt));
  }

  // パスワードを試してメタ情報を復号する。違えば例外
  async function unlock(parsed, pw) {
    const key = await KM.deriveKey(pw, parsed.salt, parsed.h.iter);
    const pt = await crypto.subtle.decrypt(
      { name: 'AES-GCM', iv: iv(parsed.nonce, META_INDEX), additionalData: cat(parsed.prefix, te.encode('meta')) }, key, parsed.metaCt);
    const meta = JSON.parse(td.decode(pt));
    const size = Number(meta.size) || 0;
    return { key, nonce: parsed.nonce, prefix: parsed.prefix, chunk: parsed.h.chunk, size, n: chunkCount(size, parsed.h.chunk), meta, dataOffset: parsed.dataOffset };
  }

  function ctLen(ctx, i) { return ptLen(ctx, i) + TAG; }

  async function decryptChunk(ctx, i, ct) {
    return new Uint8Array(await crypto.subtle.decrypt(
      { name: 'AES-GCM', iv: iv(ctx.nonce, i), additionalData: aad(ctx.prefix, i, i === ctx.n - 1) }, ctx.key, ct));
  }

  // 本体のストリームを読みながら復号し、Blob の配列を返す
  async function decryptStream(ctx, reader, onProgress, isAborted) {
    const q = [], parts = []; let qlen = 0, got = 0;
    function take(n) {
      const out = new Uint8Array(n); let o = 0;
      while (o < n) {
        const h = q[0], k = Math.min(h.length, n - o);
        out.set(h.subarray(0, k), o); o += k;
        if (k === h.length) q.shift(); else q[0] = h.subarray(k);
      }
      qlen -= n; return out;
    }
    for (let i = 0; i < ctx.n; i++) {
      const need = ctLen(ctx, i);
      while (qlen < need) {
        if (isAborted && isAborted()) throw new Error('ABORT');
        const { done, value } = await reader.read();
        if (done) throw new Error('truncated');
        q.push(value); qlen += value.length; got += value.length;
        if (onProgress) onProgress(got);
      }
      parts.push(new Blob([await decryptChunk(ctx, i, take(need))]));
    }
    return parts;
  }

  return { CHUNK, prepare, encryptChunk, parsePrefix, unlock, decryptChunk, decryptStream, ctLen };
})();
</script>

  // Drive API のレジューム可能アップロード（暗号化しながら8MBずつ送る）
  async function uploadOne(file, pw, hide, onProgress) {
    const ctx = await KB.prepare(file, pw);
    const d = await drive();
    const rnd = Array.from(crypto.getRandomValues(new Uint8Array(6)), b => b.toString(16).padStart(2, '0')).join('');
    const driveName = hide ? `kgm-${rnd}.kgm` : `${file.name}.kgm`;
    const init = await fetch('https://www.googleapis.com/upload/drive/v3/files?uploadType=resumable&fields=id', {
      method: 'POST',
      headers: { Authorization: 'Bearer ' + d.token, 'Content-Type': 'application/json; charset=UTF-8' },
      body: JSON.stringify({ name: driveName, parents: [d.folderId], mimeType: 'application/octet-stream' }),
    });
    if (init.status === 401) { st.drive = null; throw new Error('認証の期限が切れました。もう一度お試しください。'); }
    const session = init.headers.get('Location');
    if (!init.ok || !session) throw new Error('アップロードを開始できませんでした（' + init.status + '）');

    const q = [ctx.head]; let qlen = ctx.head.length, sent = 0;
    function take(n) {
      const out = new Uint8Array(n); let o = 0;
      while (o < n) {
        const h = q[0], k = Math.min(h.length, n - o);
        out.set(h.subarray(0, k), o); o += k;
        if (k === h.length) q.shift(); else q[0] = h.subarray(k);
      }
      qlen -= n; return out;
    }
    for (let i = 0; i < ctx.n; i++) {
      if (st.upAbort) throw new Error('ABORT');
      const ct = await KB.encryptChunk(ctx, i);
      q.push(ct); qlen += ct.length;
      while (qlen >= PIECE) {
        const piece = take(PIECE);
        await putPiece(session, piece, sent, ctx.total, p => onProgress(sent + p, ctx.total));
        sent += piece.length; onProgress(sent, ctx.total);
      }
    }
    if (qlen > 0) {
      const piece = take(qlen);
      await putPiece(session, piece, sent, ctx.total, p => onProgress(sent + p, ctx.total));
      sent += piece.length;
    }
    onProgress(sent, ctx.total);
  }

  function putOnce(url, bytes, start, total, onProg) {
    return new Promise((resolve, reject) => {
      const x = new XMLHttpRequest();
      st.upXhr = x;
      x.open('PUT', url);
      x.setRequestHeader('Content-Range', `bytes ${start}-${start + bytes.length - 1}/${total}`);
      x.upload.onprogress = ev => { if (ev.lengthComputable) onProg(ev.loaded); };
      x.onload = () => resolve({ status: x.status, range: x.getResponseHeader('Range') });
      x.onerror = () => reject(new Error('通信エラー'));
      x.onabort = () => reject(new Error('ABORT'));
      x.send(bytes);
    });
  }
  async function putPiece(url, piece, start, total, onProg) {
    let off = 0, tries = 0;
    while (true) {
      if (st.upAbort) throw new Error('ABORT');
      let r;
      try { r = await putOnce(url, piece.subarray(off), start + off, total, p => onProg(off + p)); }
      catch (e) {
        if (errMsg(e) === 'ABORT' || ++tries > 4) throw e;
        await new Promise(res => setTimeout(res, 1500 * tries));
        continue;
      }
      if (r.status === 200 || r.status === 201) return;
      if (r.status === 308) {
        // 受け取られた位置を確認し、足りない分があれば続きを送る
        const m = r.range && /bytes=0-(\d+)/.exec(r.range);
        const committed = m ? Number(m[1]) + 1 : start + piece.length;
        if (committed >= start + piece.length) return;
        off = Math.max(0, committed - start);
        continue;
      }
      if (r.status >= 500 && ++tries <= 4) { await new Promise(res => setTimeout(res, 1500 * tries)); continue; }
      throw new Error('アップロードに失敗しました（' + r.status + '）');
    }
  }

    st.sessionPw = null;

使い方

  • 初めて開くと、マイドライブに「鍵メモ」フォルダが自動で作られます。一覧にはこのフォルダのファイルだけが表示されます。
  • 新規メモ：ファイル名とパスワードを決めて本文を書き、「保存」を押すとドライブにファイルができます。
  • 写真・ファイルを追加：写真、動画、PDFなど、どんな拡張子のファイルでも選べます（複数可）。暗号化してから送るので、ドライブには中身の読めない .kgm ファイルとして保存されます。「ドライブ上のファイル名も隠す」にチェックすると、ドライブでのファイル名も「kgm-xxxx.kgm」になり、元の名前は開いたときだけ表示されます。
  • 開く：一覧のファイルをタップしてパスワードを入れます。画像・動画・音声・テキストはその場で表示され、それ以外のファイルは「端末に保存」で取り出せます。
  • 直接リンク：一覧の各ファイルの右端、またはファイルを開いたときの上部にある「リンク」を押すと、そのファイル専用のURL（ウェブアプリのURLの末尾に ?id=ファイルID が付いたもの）が表示されます。このURLを開くと一覧を経由せずにパスワード入力になり、そのまま編集画面や表示画面に進みます。ブックマークやホーム画面に追加しておくと便利です。リンクを開けるのは自分のGoogleアカウントだけです。
  • パスワードの記憶：一度入力したパスワードは「ロック」するまで覚えておき、同じパスワードのファイルは入力なしで開けます。
  • 保存（メモ）：暗号化した内容で、ドライブ上のファイルを直接上書きします。開いたあとに別の端末で同じメモが更新されていた場合は、上書きしてよいか確認が出ます。
  • 削除：ドライブのゴミ箱に移動します。30日以内ならドライブから元に戻せます。
  • ロック：覚えていたパスワードと、表示中の内容をメモリから消します。アプリを離れて5分たつと自動でロックされます（未保存の変更があるときや、アップロード中はロックしません）。

  • 保存（アップロード）は暗号化しながら少しずつ送るので、数GBのファイルでも端末のメモリはほとんど使いません。時間は通信速度しだいで、モバイル回線なら100MBで1〜2分が目安です。
  • 開くときは、復号したファイル全体をいったん端末のメモリに置いてから表示します。そのため、扱える大きさは端末のメモリで決まり、特にiPhoneのSafariは大きなファイルでタブが落ちやすくなります。

注意点

パスワードを忘れると復元できません

パスワードはどこにも保存されません。忘れた場合、作った本人を含めて誰もファイルを開けなくなります。

複数のGoogleアカウントにログインしている場合

スマホのブラウザで複数のアカウントにログインしていると、Apps Script のウェブアプリがエラーになることがあります。スクリプトを作ったアカウントだけでログインするか、そのアカウントだけを使うブラウザで開いてください。

承認画面の「ドライブのすべてのファイル」について

Apps Script の仕組み上、承認画面ではドライブ全体へのアクセスを求められます。実際にコードが読み書きするのは「鍵メモ」フォルダのファイルだけで、アクセスできるのも自分のアカウントだけです。

「端末に保存」したファイルは暗号化されていません

取り出したファイルは普通のファイルとして端末に保存されます。用が済んだら削除してください。

アップロード中は画面を開いたままに

スマホでは、ほかのアプリに切り替えたり画面を消したりすると、ブラウザの処理が止まって送信が失敗することがあります。途中で止まったファイルはドライブに保存されないので、もう一度追加してください。

コードを修正したとき

保存しただけでは反映されません。「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」で更新してください。URLは変わりません。

ファイル形式

ほかのツールで復号したいときの参考にしてください。どちらも鍵は PBKDF2-SHA256（パスワード, ソルト, 反復回数）で作る256ビット鍵で、AES-256-GCM で暗号化しています。

メモ（.txt）

  • 1行目：#kagimemo v1 pbkdf2-sha256 600000 aes-256-gcm（AES-GCM の追加認証データとしても使用）
  • 2行目以降：Base64（ソルト16バイト ＋ IV12バイト ＋ 暗号文と認証タグ）。76文字ごとに改行

写真・動画・任意のファイル（.kgm）

  • 先頭：KGMB ＋ バージョン1バイト ＋ ヘッダ長（4バイト）＋ ヘッダJSON（反復回数、ソルト、チャンクサイズ4MB、ノンス8バイト）
  • 続いて：メタ情報（元のファイル名・種類・サイズ・更新日時）の暗号文の長さ（4バイト）と暗号文
  • 残り：本体を4MBずつ暗号化したチャンクの並び（各チャンクに16バイトの認証タグ）
  • IV はノンス ＋ チャンク番号。追加認証データにヘッダ・チャンク番号・最終チャンクかどうかを含めるので、チャンクの入れ替えや切り詰めも検出できます
